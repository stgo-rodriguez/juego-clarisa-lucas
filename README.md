# Juego Clarisa + Lucas

Web interactiva de soporte para el juego de mesa.

## Funciones
- Dado D6.
- Mazo Infancia · Clarisa.
- Mazo Infancia · Lucas.
- Mazo Juventud.
- Mazo Adultez.
- Cartas cíclicas: la carta anterior vuelve al fondo al sacar la siguiente.
- Mezcla aleatoria en los mazos habilitados.
- Colores diferenciados por mazo.
- Iconos de recursos: ❤️ Amor, 👤 Personalidad, 📖 Conocimiento y 💰 Dinero.
- Estado de los mazos persistido localmente en el navegador.
